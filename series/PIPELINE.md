# 可复用制作流程

## 1. 从一个经验立项

写清：发生了什么、哪一处矛盾值得看、候选主张是什么、哪些内容尚未确定。先区分事实陈述、作者立场和艺术隐喻。

通过条件：主张能用一句普通话表达，而且存在合理的不同看法。不能只剩“科技改变生活”“艺术治愈心灵”等大词。

## 2. 把命题转成形式问题

为这期选择一种主要运动逻辑、一种材料关系和一个声音规则。写出它们如何随观点变化。不要先堆艺术风格名称再补一段文案。

通过条件：即使暂时关闭字幕，画面仍能显出某种有意义的关系变化。

## 3. 研究与素材登记

优先博物馆、艺术家、出版机构或学术原始来源。记录作品名称、作者、日期、馆藏编号、图片地址、权利状态与下载日期。公开可看不等于可再使用。受限素材不用“作者很早去世了”代替授权判断。

生成素材单列：生成工具、实际提示词、是否使用参考图、哪些形象为虚构。不得把生成场景当作历史影像。没有付费素材、订阅、外部 API 预算的批准，就不自行购买。

## 4. 形成脚本与短样

先做分镜与双语文本，再做 12–20 秒的真正声画样段。短样要验证运动、材质、字幕、声音，不以静态海报或自动平移图片代替。

作者确认观点、语气与视觉方向后，才进入下一期全片。这个系列没有默认的后续自动开工权限。

## 5. 完成主片

固定随机种子、记录字体与依赖；原作、局部、转化与原创解释分别标记。保持安全字幕区与足够阅读时间。需要旁白时单独决定语言、声音授权与费用；不默认使用或克隆某个人的声音。

## 6. 检查

- 内容：史实、译文、引用、观点归属、素材许可
- 视觉：实际像素、字幕边界、运动连续性、遮挡、转场、片尾
- 声音：完整声道、响度、真峰值、无意静音、音画同步；能做听审时还应实际听审
- 文件：完整解码、帧数、时长、编码兼容性、文件大小与校验值
- 网页：实际播放与跳转、键盘、手机布局；环境阻塞的检查必须单独注明，不能当作通过

001 的技术音频检查、解码和像素检查已完成；浏览器交互检查受预览访问限制，未完成。技术音频分析不冒充人工听审。

## 7. 归档与交付

一部作品包含：作者原始请求、明确的后续修订、制作说明、实际生成提示词、分镜、字幕、素材记录、源代码、最终影片与检查结果。

为聊天提供小文件版；保留较高码率版本。GitHub 用于私密创作与版本记录，作品网页用于观看；是否公开、发到什么平台、用什么文案，由作者另行决定。

## 8. 下一期的启动条件

先复盘一件有效的事和一件需要改变的事，再选择下一期。只有收到明确的新一期制作指令，才进入完整生产。没有自动排期、自动发帖或无限延展任务。
