# 私密创作台原型

入口为 `index.html`；通过静态服务器打开本目录或仓库根目录即可。页面不需要后端、密钥或新订阅。

已实现：主题/感受/候选观点/边界输入；明确规则形成提案草稿；真实002短样播放；针对具体时刻记录反馈；浏览器本地保存；导出JSON创作单。

未实现：调用模型生成提案、无人值守生成完整影片、自动接收导出文件、自动发布、云端同步、用户账户和计费。因此界面不会把模板辅助称为AI影片生成器。

保存范围：仅当前浏览器的 localStorage。导出文件由使用者决定如何分享，不自动传输给任何第三方。私密Site在现有作品站的 `series.html` 路径部署时，使用同样界面，仅替换媒体相对路径。

当前已完成源码链接、JavaScript语法、提案/保存/导出事件的独立逻辑检查；云浏览器实际交互与手机布局测试受此前预览环境限制，没有宣称通过。
