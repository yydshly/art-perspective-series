# 艺术起始词创作台

这是现有产品原型在用户纠正后的有效版本。原来强制填写生活观点的入口已移除。

实际功能：艺术起始词、领域、可选氛围/情绪、材料与构图、运动/音乐、边界；明确模板整理工作提案；母题首片播放；观看反馈；当前浏览器保存；导出JSON。

两支失败002只放在折叠归档中，并明确标注均未通过。当前没有默认下一期“暂停”主题，也不渲染新v3。

原型不调用模型生成完整影片，不自动接收导出文件、不公开发布、不收费。保存只在浏览器localStorage；新版使用独立键，不删除旧版用户草稿。JSON导出前同步当前输入，且不赋予自动开工或公开发布权限。

静态页面为index.html。部署到既有私密Site的series.html时仅调整媒体相对地址。已执行源码/事件逻辑检查；实际浏览器交互、手机布局和听审未全面验证，不能声称完成。
