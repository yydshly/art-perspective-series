# 水面之内 / Within the Surface

新艺术方向的36秒研究样段，尚待观看反馈。这不是被否定的《暂停的权利》第三次换皮，也不是完整成片已经得到认可。

## 艺术入口

莫奈水园的两种空间组织：1900《Water Lily Pond》中可辨认的桥、植物与反射；1906《Water Lilies》中由近距离笔触、色层和水面组织的空间。研究图像与材料的关系，不预设生活结论。

## 制作边界

原作完整呈现，局部与材质运动转译分开标记。动画采用不规则、保留源图油彩变化的纹理片段形成解释性空间，不是重建莫奈作画过程，不是原作真实的三维扫描，也不让桥或花作虚构角色表演。没有新生成的“莫奈风”替代图。

音乐为本次数学合成的原创声景，改变音符间隔、音域和共振关系；没有采样商业录音或调用新收费接口。只有片名和必要作品标注，中英双语，不加入生活口号。

## 来源

两幅均为芝加哥艺术博物馆图像。官方API标记public domain；当前官方图片服务受安全验证阻塞，使用Commons明确CC0的博物馆原文件镜像，经正常浏览器取得，SHA-1与镜像记录一致，馆藏号与API一致。见production/assets/SOURCES.json。不得把来源写成自行生成的绘画。
