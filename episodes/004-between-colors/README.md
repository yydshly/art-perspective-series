# 色彩之间 / Between Colors

36秒声画研究样段，尚未获得用户认可。

从修拉《马戏团巡演》的夜色与色点进入，观看距离逐渐变化，画面展开为原作色彩构成的运动层次，再重新聚合。原作、局部与原创转译组成完整短段，不附加人生结论。
